# 演示数据包（Demo）

这是一份**开箱即用的演示数据库**：里面只有虚构的演示账号、演示分组和示例数据，没有任何真实用户信息。把它和仓库里的前端、钩子拼起来，就是一个能直接登录体验的完整平台。

## 里面有什么

- **演示分组**：演示一组（组长：王组长）、演示二组
- **门户页面**：欢迎页、记账本、修仙打妖兽（小游戏）
- **示例应用**：「示例记账本」（全员可读可写，8 条示例账目 + 1 条在回收站）、「组长的小金库」（仅负责人可见，演示权限隔离）
- **模板**：公告页、图文页、链接页、通用记录页、记账本（应用型）——可从门户「从模板新建门户」直接试建

## 怎么跑起来

1. 下载 [PocketBase v0.32+](https://pocketbase.io) 二进制。
2. 建一个目录，把仓库的 `pb_public/`、`pb_hooks/` 放进去，再把本目录的 `pb_data/` 也放进去（三者同级）。
3. 启动：
   ```bash
   ./pocketbase serve --http=127.0.0.1:8090 --dir=./pb_data --publicDir=./pb_public
   ```
4. 浏览器打开 http://127.0.0.1:8090 ，用上面的演示账号登录即可。

## 安全提醒

这份数据**只用于演示**：账号密码全是公开的示例值。正式部署时请删除全部演示账号（含超级管理员 super@example.com）并重建自己的账号体系，切勿把演示库直接当生产库使用。
